## 📖 Overview

FinSack bridges the gap between theoretical finance and real-world application. Designed specifically for students, it offers a deeply immersive "Web OS" experience right in the browser. By combining interactive, gamified learning modules with professional-grade live market screening tools, FinSack transforms financial literacy from a chore into an engaging, practical experience.

## ✨ Key Features

* **Desktop-in-Browser UI:** A seamless, windowed operating system interface built entirely on the web for intuitive multitasking and professional aesthetics.
* **Gamified Education:** Interactive modules, quizzes, and learning paths that break down complex financial and trading concepts into digestible milestones.
* **Live Market Screening:** Real-time stock scanners and technical analysis tools integrated directly into the dashboard.
* **High-Performance Animations:** Smooth, Awwwards-level interactions and scrollytelling powered by Framer Motion and GSAP.
* **Responsive Architecture:** Fully optimized for both desktop and mobile browsers without sacrificing the "OS" feel.

## 🛠️ Tech Stack

* **Framework:** [Next.js (App Router)](https://nextjs.org/)
* **Library:** [React.js](https://react.dev/)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Animations:** [Framer Motion](https://www.framer.com/motion/) & [GSAP](https://gsap.com/)
* **Deployment:** [Vercel](https://vercel.com)
